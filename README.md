# Agenda de contactos

Proyecto de práctica de Git.

## Cómo usar

Cada archivo del proyecto sirve para lo siguiente:

- **README.md**: describe el proyecto y cómo usarlo.
- **.gitignore**: lista lo que Git no debe guardar.
- **contactos.txt**: contactos de la agenda.
- **tareas.txt**: tareas pendientes.
- **compras.txt**: lista de compras.
